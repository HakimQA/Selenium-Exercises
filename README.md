# Selenium Automation Projects

This repository contains my Selenium WebDriver automation practice projects developed using Java, Maven, and TestNG.

## Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* Git & GitHub
* IntelliJ IDEA

## Projects Included

### 1. FlightBookingFullFlow

Automates a flight booking flow including:

* Source and destination selection
* Date picker handling
* Passenger selection
* Flight search

### 2. SauceDemo

End-to-end automation of the SauceDemo application:

* Login functionality
* Product selection
* Add to cart
* Checkout process

### 3. Selenium_Date_Picker_Excercises

Date picker automation exercises:

* Current date selection
* Future date selection
* Reusable date picker methods
* Dynamic date handling

### 4. Selenium_Dropdowns_Excercises

Dropdown automation exercises:

* Static dropdowns
* Dynamic dropdowns
* Multiple selection dropdowns

### 5. BasicSeleniumFramework

Basic Selenium framework implementation using:

* Page Object Model (POM)
* TestNG
* Reusable utilities

## Learning Objectives

* Web element identification using XPath and CSS Selectors
* Dynamic element handling
* Wait strategies
* Framework design
* Test automation best practices
